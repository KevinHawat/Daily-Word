THE DAILY WORD — AUTOMATIC BIBLE LOADING

The website now automatically tries to fetch ./bible.json on startup.
To enable automatic loading, place a valid daily-word-njb-v1 JSON file
named bible.json in the same directory as index.html and deploy both.
The Bible tab still supports manual import as a fallback if bible.json is absent.

IMPORTANT COPYRIGHT/PRIVACY WARNING:
This ZIP does NOT include the NJB text. Uploading your NJB JSON to
GitHub Pages would make its full copyrighted contents publicly accessible.
Only deploy Bible text you have the right to redistribute, or use
the private import feature instead.
